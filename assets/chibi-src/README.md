# 치비 일러스트 원본

이 폴더는 **배포되지 않는다.** Next.js는 `public/`만 정적으로 서빙하므로,
용량이 큰 원본(장당 0.4~1.8MB)을 여기 두면 버전 관리는 유지하면서
배포 산출물에서는 빠진다.

## 원본을 그대로 쓰지 않는 이유

- 캐릭터 주변 여백이 커서 UI에 넣으면 실제 그림이 작게 보인다
- 리그/구단 로고(WKBL·BNK SUM·CHAMPIONS)와 작가 워터마크가 함께 박혀 있다
- 장당 0.4~1.8MB로 빈 상태 일러스트에 쓰기엔 지나치게 무겁다

## 변환

```
node scripts/crop-chibi.mjs <파일명.PNG> [...]
```

스크립트가 하는 일:

1. 테두리에서 플러드필로 **바깥 배경만** 투명화 (흰 유니폼 등 내부는 보존)
2. 남은 전경의 연결 요소 중 **가장 큰 것(캐릭터)만** 유지
   → 떨어져 있는 로고·워터마크·공·별 장식이 자동으로 제거된다
3. bbox + 여백으로 크롭, 긴 변 640px, 투명 WebP로 `public/images/chibi/`에 출력

결과물은 소문자 `.webp`로 정규화된다. macOS는 파일명 대소문자를 구분하지
않지만 배포 환경(Linux)은 구분하므로, 대문자 `.PNG`를 코드에서 직접
참조하면 로컬에서만 동작하고 배포에서 404가 난다.

새 일러스트를 쓰려면 변환 후 `src/shared/ui/chibi.ts`에 항목을 추가한다.
